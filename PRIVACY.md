# Privacy policy — WhatsApp Privacy Shield

WhatsApp Privacy Shield by Rahul Saini changes how matching WhatsApp Web elements are displayed. It does not collect, store or transmit chat contents, contact details, usage analytics or personal data. It does not use cookies or browser storage. On/off state and blur strength remain in the current page's memory and reset on reload.

The content script runs only on https://web.whatsapp.com/. It needs access there to insert visual styles and controls, and to locate interface elements. It makes no network requests. An optional website link opens irahulsaini.com only when clicked; that visit is separate from the extension and subject to the site's policies.

Blur is a visual effect and does not protect underlying data. Some surfaces may remain visible. The extension is not affiliated with WhatsApp or Meta.
